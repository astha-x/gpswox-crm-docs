# Customer Support Ticketing System

The Support Ticketing System handles customer issue reporting, interactive troubleshooting questionnaires, ticket assignments, and file attachments.

---

## 1. Creating a Support Ticket

When a customer reports an issue:
1. Navigate to **Support -> Create Ticket**.
2. Select the affected vehicle and problem category (e.g. Offline Device, Ignition Alarm Issue, Billing Query).
3. Answer automated troubleshooting questions to help support agents diagnose the issue faster.
4. Attach screenshots or documents if applicable.

---

## 2. Managing & Resolving Tickets

- Support agents can assign tickets, update priority (`Low`, `Medium`, `High`, `Urgent`), and reply to customers.
- Agents can use **Quick Templates** to send standardized troubleshooting answers instantly.
