# Vehicle Management & GPSWOX Devices

Manage vehicles, assign device IMEIs, set installation dates, and link vehicles to customer accounts.

---

## 1. Adding & Editing Vehicles

When adding or editing a vehicle:
- **Vehicle Name / Registration**: Vehicle license plate or nickname.
- **GPSWOX Device ID / IMEI**: Connect the CRM vehicle record to the GPSWOX tracking server.
- **SIM Number**: Mobile SIM number inside the GPS tracker device.
- **Monthly Bill Amount**: Individual monthly subscription rate for this vehicle.
- **Bill Owner**: Select the customer responsible for paying this vehicle's monthly bill.

---

## 2. GPSWOX Synchronization

> [!NOTE]
> Vehicle records can be automatically synchronized with your GPSWOX server using the background sync engine. Navigate to **Settings -> GPSWOX Server Config** to run device synchronization.
