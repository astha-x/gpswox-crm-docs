# System Settings & Database Backups

Configure global system parameters, SMS gateways, database backup schedules, and activity log retentions.

---

## 1. Automated Database Backups

- **Local & Remote Backups**: Create scheduled database backups stored locally or exported to remote FTP servers.
- **Backup Restoration**: Restore database backups safely using OTP verification.

---

## 2. SMS Templates & Site Settings

- **SMS Templates**: Customize automated SMS notifications for bill alerts, payment receipts, and OTP verification messages.
- **Site Logos & Favicon**: Update system logos and branding assets under **Settings -> Site Settings**.
